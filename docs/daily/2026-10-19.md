    # Daily Log — 19 ตุลาคม 2569

## สิ่งที่ทำวันนี้

### 1. Hero หน้าแรก (Backlog ข้อ 1)

- เอา eyebrow "PROFESSIONAL SALON PRODUCTS" ออก
- หัวข้อใหญ่เปลี่ยนเป็น **"Beauty Up"** (Beauty สีเข้ม + Up สีชมพูตัวเอียง) ใส่แสงสีชมพูเบลอด้านหลัง
- ย้าย "เรามอบสิ่งที่ดีที่สุด เพื่อลูกค้าของคุณ" มาเป็น subheadline ใต้ "Beauty Up" (1 บรรทัด)
- ปุ่ม "ชมสินค้า" เพิ่มไอคอนลูกศรในวงกลมสีชมพู — ปุ่ม/สถิติด้านล่างไม่เปลี่ยน
- พื้นหลังเปลี่ยนเป็น gradient ชมพู→ขาว แก้ปัญหาช่องว่างลอยก่อนถึงแถบแบรนด์

**ไฟล์:** `home-hero.tsx`, `i18n/th.ts`, `i18n/en.ts`, `globals.css`

### 2. แถบแบรนด์ — แยก Salon Product / Counter Brand

- แยกเป็น 2 แถว: **Salon Product** (Fanola, Nook, Sweet) กึ่งกลาง นิ่ง ไม่เลื่อน / **Counter Brand** (14 แบรนด์) เลื่อน marquee เหมือนเดิม
- โชว์โลโก้ + ชื่อแบรนด์คู่กัน (ถ้ายังไม่มีโลโก้ → จุดสีชมพู + ชื่อแทน)
- Tag "Salon" เปลี่ยนสีให้เข้าชุดกับ tag "Luxury"

**ไฟล์:** `brand-marquee.tsx`, `page.tsx`

### 3. เพิ่ม Section "Counter Brand" แบบการ์ด

- เพิ่มการ์ดแบรนด์ Counter Brand ต่อจาก Salon Product (โชว์สูงสุด 3 แบรนด์หน้าแรก)
- เปลี่ยนหัวข้อ "Imported Brands" → **"Salon Collection / ผลิตภัณฑ์ซาลอน"** คู่กับ **"Luxury Collection / เคาน์เตอร์แบรนด์"**
- แก้บั๊ก: โลโก้แบรนด์ (เช่น CLARINS) เคยโดนครอปจนเห็นไม่ครบ → เปลี่ยนเป็นเห็นโลโก้เต็มตัว พื้นขาว (ใช้กับหน้า `/products` ด้วย)

**ไฟล์:** `page.tsx`, `products/page.tsx`, `ui.tsx`

### 4. Footer + หน้า About

- Footer: เอากรอบ tag ชื่อแบรนด์ออก เปลี่ยนเป็นข้อความเรียบ คั่นด้วยจุดสีชมพู
- About: ย้ายประโยค "ก่อตั้งโดย คุณเอมี่ ภรภัทร โสธนไพศาล" ไปท้ายย่อหน้า + แก้ "เมื่อพ.ศ." → "ในปี พ.ศ."

**ไฟล์:** `site-footer.tsx`, `i18n/th.ts`

### 5. Hero ทุกเมนู ให้สไตล์เดียวกับหน้าแรก

- แก้ component กลาง `PageHero` (ใช้ร่วม 16 หน้า: About, Courses, Contact, Shop, Products ฯลฯ) → พื้นหลัง gradient ชมพู-ขาว + eyebrow มีเส้นชมพูนำหน้า
- ยังไม่ทำ: หน้า VIP Customer และหน้าหมวดหมู่สินค้าแต่ละแบรนด์ (มี Hero เฉพาะตัวอยู่แล้ว รอตัดสินใจ)

**ไฟล์:** `ui.tsx`

### 6. ลิงก์แบรนด์ไปเว็บไซต์หลัก (Backlog ข้อ 9)

- ยืนยัน: ช่อง "เว็บไซต์แบรนด์" มีอยู่แล้วใน Admin (ไม่ต้องแก้โค้ด) และหน้า `/products/[brand]` ใช้งานอยู่แล้ว
- เพิ่มใหม่: การ์ด Counter Brand บนหน้าแรก ถ้าแบรนด์มีลิงก์เว็บไซต์ → คลิกไปเว็บไซต์จริงเลย (เปิดแท็บใหม่) ถ้ายังไม่มี → ไปหน้า `/shop` เหมือนเดิม

**ไฟล์:** `page.tsx`, `i18n/th.ts`, `i18n/en.ts`

### 7. แก้บั๊กการ์ดหมวดหมู่สินค้าในหน้าแบรนด์ (เช่น Fanola)

- เจอจุดสับสน: มี 2 ที่ที่ดูเหมือนใช้แก้ "หมวดหมู่หลักของแบรนด์" ได้ แต่จริงๆ หน้าเว็บใช้ข้อมูลจาก **"เมนูและหน้าเว็บ" (menu-items)** เท่านั้น ไม่ได้ใช้จาก "แบรนด์ → หมวดหมู่หลักประจำแบรนด์" (เป็นข้อมูลคนละชุดที่ไม่ผูกกัน — ยังไม่ได้แก้ความซ้ำซ้อนนี้ รอตัดสินใจว่าจะเคลียร์จุดไหนออก)
- แก้บั๊ก: กริดการ์ดหมวดหมู่ fix ไว้ที่ 4 คอลัมน์ตายตัว พอเพิ่มการ์ดที่ 5 เลยตกไปอยู่แถวใหม่โดดๆ → แก้ให้จำนวนคอลัมน์ปรับตามจำนวนการ์ดจริงอัตโนมัติ (แก้ทั้งฝั่งเว็บจริงและฝั่ง preview ใน Admin)

**ไฟล์:** `menu-content-renderer.tsx` (web), `menu-item-visual-editor.tsx` (admin)

### 8. เปลี่ยนชื่อเมนู "ร้านบิวตี้อัพ" (Backlog ข้อ 8)

- เป็นการแก้ข้อมูลใน Admin ไม่ใช่โค้ด — พี่แก้เองผ่าน Admin → เมนูและหน้าเว็บ
- เปลี่ยนจาก "ร้านบิวตี้อัพ / BeautyUp shop" → **"เคาน์เตอร์แบรนด์ / Counter Brand"** (href `/shop` เหมือนเดิม) ตรวจสอบจาก database แล้วว่าบันทึกสำเร็จ ✅

**หมายเหตุปฏิบัติการ:** ระหว่างวัน API dev server (พอร์ต 4000) หลุดไป 2 รอบ (ไม่เกี่ยวกับโค้ดที่แก้) ผมช่วยรีสตาร์ตให้ และมีจังหวะที่ผมรัน dev server เองไปชน port กับที่พี่สั่ง `pnpm dev` เอง — แก้ไขและเคลียร์ port ให้เรียบร้อยแล้ว
