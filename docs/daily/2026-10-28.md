### 1. ระบบตัวกรองหมวดหมู่มีเดียบนหน้าเว็บไซต์ (`/members/media`)

**ปัญหา:** หน้าเว็บ `/members/media` เดิมใช้คอมโพเนนต์รวมกับบทความและกิจกรรม มีเพียงแท็บระดับบน `[บทความ] [กิจกรรม] [มีเดีย]` แต่ไม่มีแถบแท็บย่อยสำหรับเลือกกรองตาม "หมวดหมู่มีเดีย" (Media Category) ที่สร้างไว้ใน Admin ทำให้ผู้เข้าชมเว็บไซต์ไม่สามารถแยกดูสื่อตามกลุ่มสินค้าหรือกิจกรรมได้ และบนการ์ดแสดงผลเพียงคำว่า "มีเดีย · วันที่" ไม่ระบุชื่อหมวดหมู่

**แก้ไข:**
- เพิ่มฟังก์ชัน `getMediaCategories(lang)` ใน `apps/web/src/lib/data.ts` เพื่อดึงหมวดหมู่มีเดียที่เปิดใช้งาน (`isActive: true`) เรียงตามลำดับ (`sortOrder`)
- ปรับแต่ง `mediaAsPost` ให้แนบข้อมูล `category` ของมีเดียส่งต่อไปยังรายการแสดงผล
- ปรับปรุงหน้า `/[lang]/members/[type]/page.tsx`:
  - เมื่อเปิดเข้าหน้ามีเดีย (`type === "MEDIA"`) ระบบจะแสดงแถบปุ่มตัวกรองหมวดหมู่ (Category Filter Pills): `[ทั้งหมด]` และรายชื่อหมวดหมู่มีเดียทั้งหมด เช่น `[No Yellow Care]` ฯลฯ
  - รองรับการคลิกเลือกหมวดหมู่เพื่อกรองข้อมูลแบบไดนามิกผ่าน URL Query Parameter `?cat=slug`
- ปรับปรุงการ์ดแสดงผล `PostCard` (`apps/web/src/components/post-card.tsx`):
  - สำหรับรายการประเภทมีเดียที่มีการระบุหมวดหมู่ ระบบจะดึงชื่อหมวดหมู่มีเดียจริงมาแสดงบนการ์ดแทนคำว่า "มีเดีย" (เช่น `No Yellow Care · 15 มกราคม 2569`)

### 4. แก้ไขปัญหาวิดีโอทับซ้อนและดึงรูปหน้าปกไปใช้เป็นภาพพักวิดีโอ (Video Poster Conflict)

**ปัญหา:** เมื่อมีการใส่วิดีโอลิงก์ YouTube ร่วมกับรูปภาพในมีเดียหรือบทความ ระบบเดิมนำรูปปก (`images[0]`) ไปบังคับใช้เป็นโปสเตอร์พักหน้าจอของตัวเล่นวิดีโอ (`poster={cover}`) และไปสั่งซ่อนรูปภาพปกขนาดใหญ่ของแกลเลอรี่ภาพ (`cover={!videoUrl}`) ทำให้รูปสินค้า/รูปปกถูกปุ่ม Play สีชมพูขนาดใหญ่ทับไว้ตรงกลาง และแกลเลอรี่ด้านล่างถูกลดทอนเหลือแค่รูปย่อเล็กๆ

**แก้ไข:**
- ปลด `poster={cover}` ออกจากคอมโพเนนต์ `VideoPlayer` เพื่อให้ตัวเล่นวิดีโอใช้ภาพปกวิดีโอจริงจาก YouTube เองโดยตรงอย่างเป็นอิสระ
- กำหนดให้แกลเลอรี่รูปภาพ (`MediaGallery`) คงการแสดงผลรูปหน้าปกขนาดใหญ่ (`cover={true}`) ไว้อย่างถูกต้องสวยงาม
- แยกส่วนกล่องวิดีโอและแกลเลอรี่รูปภาพออกจากกันอย่างชัดเจน ไม่นำปุ่มเล่นวิดีโอมาทับบนรูปถ่ายของลูกค้าอีกต่อไป

**Commit:** `305f6a2`

### 2. อัปเกรดระบบพรีวิวหน้าเว็บจริง (Live Preview) ใน Admin สำหรับ "มีเดีย" และ "หมวดหมู่มีเดีย"

**ปัญหา:** หน้าต่างพรีวิว (Live Preview Modal) ในระบบ Admin สำหรับข้อมูลมีเดีย (`media`) และหมวดหมู่มีเดีย (`media-categories`) ยังตกหล่นไปใช้กล่องพรีวิวข้อมูลทั่วไป (`renderGenericPreview`) ทำให้ไม่เห็นป้ายหมวดหมู่, ตัวเล่นวิดีโอ YouTube, แท็กค้นหา หรือตัวอย่างเลย์เอาต์จริงบนหน้าเว็บ

**แก้ไข:**
- **พรีวิวมีเดีย (`renderMediaPreview`):**
  - จำลองหน้าตาเหมือนหน้ารายละเอียดมีเดียจริง (`/[lang]/members/media/[slug]`) แบบ 100%
  - แสดง Breadcrumb นำทาง (`มุมสมาชิก / มีเดีย`)
  - แสดงหัวข้อและป้ายชื่อหมวดหมู่มีเดียสีชมพูแบรนด์ พร้อมวันที่เผยแพร่
  - ตรวจจับลิงก์ YouTube อัตโนมัติ และฝังตัวเล่นวิดีโอ YouTube Player ในหน้าพรีวิวทันที
  - แสดงแกลเลอรีรูปภาพขนาดใหญ่และรูปขนาดย่อ (Thumbnails)
  - แสดงคำโปรย (Excerpt) และเนื้อหารายละเอียด
  - แสดงป้ายแท็กคำค้นหา (`#tag`) และป้ายแบรนด์ที่เกี่ยวข้อง
- **พรีวิวหมวดหมู่มีเดีย (`renderMediaCategoryPreview`):**
  - จำลองหน้าตาของหน้า `/members/media`
  - ไฮไลต์ปุ่มแท็บหมวดหมู่ที่กำลังแก้ไขให้เห็นตำแหน่งจริงบนหน้าเว็บ
  - แสดงตัวอย่างการ์ดมีเดียจำลองที่จะมาแสดงผลอยู่ภายใต้หมวดหมู่นี้

**Commit:** `685ab33`, `f36f7f3`, `0ebf57f`

### 3. จัดทำสคริปต์เสียงสำหรับวิดีโอสอนการใช้งานระบบ Admin ผ่าน AI Text-to-Speech (TTS)

**เป้าหมาย:** จัดเตรียมสคริปต์คำพูดภาษาไทยที่จัดรูปแบบพร้อมสำหรับการคัดลอกไปวางใน AI Text-to-Speech (TTS) เพื่อนำไปพากย์เสียงวิดีโอคู่มือการใช้งานระบบหลังบ้าน

**รายละเอียดที่จัดทำ:**
- เรียบเรียงสคริปต์ทีละส่วนตามลำดับช่องในฟอร์มจริงของระบบ Admin
- อธิบายระบบ 2 ภาษา (แท็บภาษาไทย และ English) พร้อมทั้งสถานะแจ้งเตือน `ยังไม่แปลภาษาอังกฤษ` และ `แปลครบทุกช่อง`
- ปรับแต่งคำศัพท์ภาษาอังกฤษให้อ่านออกเสียงทับศัพท์ภาษาไทยที่ถูกต้อง (Phonetic Spelling) เช่น ซาลอน, ยูอาร์แอล, พีเอ็นจี, เจเปก, พีดีเอฟ, เอสอีโอ, พรีวิว
- จัดทำครอบคลุมทั้ง 5 โมดูล:
  1. **แบรนด์ (Brand):** การเลือกประเภทซาลอน/เคาน์เตอร์, โลโก้โปร่งใส, สโลแกน, แคตตาล็อก PDF, โซเชียล และปุ่มพรีวิว
  2. **หมวดหมู่หลัก (Main Category):** การเชื่อมโยงแบรนด์, การกำหนด slug URL เอง, คำอธิบายการ์ด และรูปภาพ
  3. **คอลเลกชัน (Collection):** การกรองหมวดหมู่หลักตามแบรนด์, จุดเด่น, ภาพการ์ด, ภาพแบนเนอร์ และการเลือกสีประจำคอลเลกชัน (Color Picker)
  4. **สินค้า (Product):** การเลือกหมวดหมู่หลัก/คอลเลกชัน (แบบไม่บังคับ), ราคาปกติ/ราคาลด, ป้ายแบดจ์, แท็ก SEO/AI, การอัปโหลดแกลเลอรีรูปภาพสูงสุด 20 รูป และการสลับรูปหน้าปก
  5. **หมวดหมู่มีเดีย (Media Category):** การสร้างหมวดหมู่เพื่อใช้จัดระเบียบภาพและวิดีโอบนหน้าเว็บ

### 5. อัปเกรดตัวแก้ไขข้อความ (Rich Text Editor) เป็น Tiptap WYSIWYG Editor

**ปัญหา:** ตัวแก้ไขข้อความเดิมเป็น Textarea กึ่งมาร์กดาวน์ ผู้ใช้ต้องพิมพ์หรือคลุมดำเพื่อแทรกเครื่องหมาย `**ข้อความ**`, `## หัวข้อ`, หรือ `- รายการ` ทำให้ใช้งานยาก ไม่เห็นผลลัพธ์แบบเรียลไทม์ และไม่สะดวกเหมือนการพิมพ์งานใน Word หรือ Notion

**แก้ไข:**
- ติดตั้งและอัปเกรดเป็น **Tiptap WYSIWYG Rich Text Editor** ในระบบ Admin:
  - พิมพ์แล้วเห็นผลลัพธ์การจัดรูปแบบตัวอักษรทันที (What You See Is What You Get)
  - แถบเครื่องมือครบครัน (Toolbar):
    - หัวข้อหลัก (H2), หัวข้อย่อย (H3)
    - ตัวหนา (Bold: Ctrl+B), ตัวเอียง (Italic: Ctrl+I), ขีดเส้นใต้ (Underline: Ctrl+U), ขีดฆ่า (Strike), โค้ด/เน้นคำ (Code)
    - รายการแบบจุด (Bullet List), รายการแบบตัวเลข (Ordered List), อ้างอิง/คำคม (Blockquote)
    - การแทรกลิงก์ (Link) พร้อม Modal ป้อน URL และปุ่มลบลิงก์
    - ล้างการจัดรูปแบบ (Clear Formatting), ย้อนกลับ (Undo: Ctrl+Z), ทำซ้ำ (Redo: Ctrl+Y)
  - แถบสถานะด้านล่างแสดงจำนวนคำและจำนวนตัวอักษรแบบ Realtime
  - เชื่อมต่อ `tiptap-markdown` เพื่อบันทึกและแปลงข้อความเป็น Markdown/HTML สะอาด รองรับฐานข้อมูลเดิม 100% โดยไม่มีผลกระทบต่อข้อมูลเดิม
- อัปเกรดคอมโพเนนต์ `RichText` ฝั่งหน้าเว็บ (`apps/web`): ให้รองรับการเรนเดอร์ทั้ง Markdown เดิม และ HTML Typography อย่างสวยงาม
