### 1. ระบบแกลเลอรี่รูปภาพหลายรูปสำหรับบทความและกิจกรรม (`posts`)

**ปัญหา:** บทความและกิจกรรมเดิมใส่รูปภาพได้เพียงรูปเดียว (`coverUrl`) ไม่สามารถอัปโหลดภาพบรรยากาศกิจกรรมหลายๆ รูปหรือสร้างแกลเลอรี่ภาพได้

**แก้ไข:**
- เพิ่มคอลัมน์ `images` (Array ของ URL รูปภาพ) ในตาราง `Post`
- เปลี่ยนช่องอัปโหลดใน Admin เป็น **`ImageGallery`** รองรับการลากไฟล์รูปภาพมาวางได้หลายรูปพร้อมกัน (Drag & Drop), ลากสลับลำดับรูปภาพ, ลบรูปภาพ และกำหนดให้รูปแรกเป็นรูปปกอัตโนมัติ
- เชื่อมต่อระบบตั้งชื่อไฟล์รูปอัตโนมัติ (SEO Auto-Rename) เมื่อบันทึก เพื่อให้ชื่อไฟล์ระบุประเภทบทความ ชื่อเรื่อง และลำดับภาพ
- หน้าเว็บหน้ารายละเอียดบทความและกิจกรรม (`/[lang]/members/[type]/[slug]`): แสดงผลเป็นแกลเลอรี่ภาพขนาดใหญ่ (`MediaGallery`) พร้อมรูปตัวอย่างขนาดเล็ก (Thumbnails), ป้ายแสดงจำนวนภาพ และ Lightbox คลิกดูภาพขยายเต็มจอ

### 2. จัดระเบียบโครงสร้างเมนู แยกมีเดียออกจากบทความ/กิจกรรม และเรียงหมวดหมู่ก่อนรายการ

**ปัญหา:** เมนูมีเดียกับบทความ/กิจกรรมปนกันอยู่ในกลุ่มเดียวกัน และแถบขั้นตอน (Section Flow Bar) เรียงเอารายการข้อมูลขึ้นก่อนหมวดหมู่ ทำให้ผู้ดูแลระบบที่ต้องการสร้างหมวดหมู่ใหม่ต้องกดข้ามขั้นตอน

**แก้ไข:**
- สลับลำดับแท็บขั้นตอนการทำงานให้ **หมวดหมู่ขึ้นก่อนรายการข้อมูลเสมอ**:
  - **มีเดีย:** `1. หมวดหมู่มีเดีย` ➔ `2. คลังมีเดีย`
  - **ฟอรั่ม:** `1. หมวดหมู่ฟอรั่ม` ➔ `2. กระทู้ฟอรั่ม` ➔ `3. ความคิดเห็น`
- แยกเมนูซ้ายมือ (Sidebar) ของ **"มีเดีย"** ออกจาก **"บทความและกิจกรรม"** ให้เป็นคนละเมนูกันชัดเจน
- แยกแท็บระหว่าง **บทความ (Articles)** และ **กิจกรรม (Activities)** ให้สลับจัดการข้อมูลและดูรายการแยกหมวดหมู่ได้ทันที

### 3. ระบบพรีวิวหน้าเว็บจริงแบบ Realtime เต็มหน้าจอ (Live Preview Modal)

**ปัญหา:** เดิม Admin มีเพียงการ์ดพรีวิวขนาดเล็กที่ไม่ตรงกับหน้าเว็บจริง ผู้ดูแลระบบไม่เห็นภาพว่าเมื่อบันทึกแล้วหน้าตาบนเว็บไซต์และมือถือจะเป็นอย่างไร

**แก้ไข:**
- เพิ่มปุ่ม **"Preview ดูตัวอย่างหน้าเว็บ"** ด้านบนของทุกฟอร์มใน Admin
- เมื่อกดปุ่ม จะแสดงหน้าต่าง **Popup พรีวิวเต็มหน้าจอ (Full-screen Modal)** มีปุ่มปิดชัดเจนที่มุมขวาบน (`✕ ปิดตัวอย่าง`)
- รองรับการสลับภาษา **ไทย (TH) / อังกฤษ (EN)** และสลับโหมดการแสดงผล **เดสก์ท็อป (Desktop) / มือถือ (Mobile)**
- อัปเดตการแสดงผลแบบ Realtime ตามข้อมูลที่กำลังพิมพ์หรือรูปที่อัปโหลดทันที โดยไม่ต้องกดบันทึกลงฐานข้อมูลก่อน
- จัดการเรื่องรูปภาพให้อัตโนมัติ: คง URL รูปภาพจาก Cloud CDN (DigitalOcean Spaces) และแปลง Local Blob เป็นภาพพรีวิวได้ถูกต้อง
- เลย์เอาต์ในโหมดมือถือปรับเป็น Single-Column แบบ Responsive เสมือนเปิดดูจากสมาร์ทโฟนจริง
- **รองรับการพรีวิวครบทุกส่วนสำคัญ:**
  - **แบรนด์ (`brands`):** พรีวิวเหมือนหน้า `/th/products` จริง (พื้นหลังขาว, โลโก้แบรนด์, คำอธิบาย, ป้ายจุดเด่น และปุ่มโซเชียล)
  - **หมวดหมู่หลัก (`main-categories`):** พรีวิวหัวเรื่องหมวด และการ์ดกริด 4 คอลัมน์
  - **คอลเลกชัน (`categories`):** พรีวิวแบนเนอร์คอลเลกชัน คำโปรย และการ์ดสินค้า
  - **สินค้า (`products`):** พรีวิวหน้ารายละเอียดสินค้าจริง แกลเลอรี่ภาพสลับดูได้ ราคา ป้ายโปรโมชั่น แท็ก SEO และกล่องสั่งซื้อ
  - **หน้าเคาน์เตอร์แบรนด์ (`shopPage`):** พรีวิวส่วน Hero, ตาราง 14 แบรนด์, รูปและคำพูด CEO และรายการสินค้า

### 4. แยกการจัดการผลิตภัณฑ์ซาลอน (`/products`) และเคาน์เตอร์แบรนด์ (`/shop`) ออกจากกัน 100%

**ปัญหา:** สินค้าซาลอนกับเคาน์เตอร์แบรนด์ปะปนกันในเมนูเดียว ทำให้สับสน และหน้า `/th/shop` ยังไม่มีเมนูสำหรับจัดการข้อความ Hero, ตาราง 14 แบรนด์ และรูปคำพูดของคุณเอมี่ (CEO) ในระบบ Admin

**แก้ไข:**
- แยกเมนูซ้ายมือ (Sidebar) ออกเป็น 2 เมนูหลัก:
  - **ผลิตภัณฑ์ซาลอน (`/products`):** จัดการเฉพาะแบรนด์/หมวด/สินค้าประเภทซาลอน (`type=SALON`)
  - **เคาน์เตอร์แบรนด์ (`/shop`):** จัดการเฉพาะแบรนด์/หมวด/สินค้าประเภทเคาน์เตอร์แบรนด์ (`type=COUNTER`)
- สร้างแถบขั้นตอนจัดการเคาน์เตอร์แบรนด์ 4 ขั้นตอน:
  - `1. เนื้อหาหน้า & รูป CEO (/shop)` (`/content/shopPage`): จัดการข้อความหัวเรื่อง Hero, ข้อความคำพูด CEO และอัปโหลดรูปคุณเอมี่ (`ceoImageUrl`)
  - `2. แบรนด์เคาน์เตอร์` (`/r/brands?type=COUNTER`): จัดการ 14 แบรนด์เคาน์เตอร์
  - `3. หมวดหมู่หลัก` (`/r/main-categories?type=COUNTER`): จัดการหมวดหมู่หลักของสินค้าเคาน์เตอร์แบรนด์
  - `4. สินค้าเคาน์เตอร์แบรนด์` (`/r/products?type=COUNTER`): จัดการสินค้าเคาน์เตอร์แบรนด์ โดยตัวเลือกแบรนด์จะกรองเฉพาะแบรนด์เคาน์เตอร์เท่านั้น ไม่ปนกับซาลอน
- หน้า `/th/shop` ฝั่งหน้าเว็บ:
  - ดึงข้อมูลจากคีย์ `shopPage` มาแสดงผลทั้ง Hero, รูปคุณเอมี่ และข้อความอย่างครบถ้วน
  - แสดงโลโก้ของแบรนด์เคาน์เตอร์ในตาราง 14 แบรนด์เมื่อมีการอัปโหลดโลโก้ใน Admin
  - เพิ่มระบบตัวกรองสินค้าตาม **แบรนด์** และ **หมวดหมู่หลัก** บนหน้าเว็บ
  - แก้ไขระบบ **Instant Cache Revalidation** (`revalidateWeb` + Fallback Secret) เพื่อให้เมื่อกดบันทึกใน Admin หน้าเว็บจะล้างแคชและแสดงผลทันทีโดยไม่ต้อง redeploy

### 5. ปรับให้หมวดหมู่หลักในสินค้าเคาน์เตอร์แบรนด์ไม่บังคับ (Optional)

**ปัญหา:** ฟอร์มสินค้าบังคับเลือกหมวดหมู่หลัก (`*`) แต่สินค้าเคาน์เตอร์แบรนด์บางรายการไม่มีการแบ่งหมวดหมู่หลัก ทำให้ผู้ดูแลระบบไม่สามารถกดบันทึกสินค้าได้

**แก้ไข:**
- ปลดเครื่องหมายดอกจัน `*` บังคับออกจากช่อง "หมวดหมู่หลัก" ในหน้าเพิ่ม/แก้ไขสินค้า
- ปรับ Schema `productInput` ให้ `mainCategoryId` เป็น `nullable` (เว้นว่างได้)
- สินค้าเคาน์เตอร์แบรนด์หรือสินค้าทั่วไปที่ไม่มีหมวดหมู่หลักสามารถกดบันทึกได้ทันที
- ปรับระบบตัวกรองคอลเลกชันให้เชื่อมโยงตามแบรนด์อัตโนมัติหากสินค้าไม่ได้ระบุหมวดหมู่หลัก

### 6. ระบบสิทธิ์ผู้ใช้งาน (Multi-Role RBAC), หน้าเปลี่ยนรหัสผ่าน (`/profile`), และตารางจัดการสิทธิ์ตามบทบาท (Permissions Matrix)

**ปัญหา:** ระบบเดิมมีเพียงสิทธิ์ ADMIN และ STAFF แบบตายตัว ไม่สามารถควบคุมได้ว่าผู้ใช้แต่ละกลุ่มจะเห็นเมนูใด หรือทำอะไรได้บ้าง (Add, Edit, Read, Delete) และไม่มีหน้าให้ผู้ใช้เปลี่ยนรหัสผ่านของตนเอง

**แก้ไข:**
- **ขยายระดับสิทธิ์ในระบบ (Role Enum):**
  - เพิ่มระดับสิทธิ์เป็น 4 ระดับ:
    1. **`ADMIN`** (ผู้ดูแลระบบสูงสุด): มีสิทธิ์เต็มทุกส่วน จัดการผู้ใช้และตั้งค่าระบบ
    2. **`MANAGER`** (ผู้จัดการระบบ): จัดการสินค้า แบรนด์ เมนู หน้าเว็บ และตอบข้อความสอบถาม
    3. **`EDITOR`** (ผู้ดูแลเนื้อหา): จัดการหน้าเว็บ บทความ กิจกรรม มีเดีย และฟอรั่ม
    4. **`STAFF`** (ทีมงานทั่วไป): ดูและตอบข้อความสอบถาม ตรวจสอบสินค้า
  - สร้าง Migration `20261027135000_add_roles` และตั้งค่าให้สั่งรัน `prisma generate` อัตโนมัติเมื่อสั่ง build API ป้องกันปัญหา Type mismatch
- **หน้าเปลี่ยนรหัสผ่านและข้อมูลบัญชี (`/profile`):**
  - เพิ่มหน้า `/profile` เข้าถึงได้จากเมนู Sidebar และไอคอนลูกกุญแจ 🔑 มุมซ้ายล่าง
  - แสดงข้อมูลบัญชีผู้ใช้ปัจจุบันและป้ายสิทธิ์
  - ฟอร์มเปลี่ยนรหัสผ่าน: ตรวจสอบรหัสผ่านปัจจุบัน, บังคับรหัสผ่านใหม่อย่างน้อย 8 ตัวอักษร, ยืนยันรหัสผ่านใหม่, มีปุ่มเปิด/ปิดตาดูรหัสผ่าน และแจ้งเตือนสถานะทันที
- **ตารางจัดการสิทธิ์ตามบทบาท (Granular Permissions Matrix):**
  - ในหน้า **ผู้ใช้หลังบ้านและการกำหนดสิทธิ์ (`/users`)** เพิ่มแท็บ **"กำหนดสิทธิ์ตามบทบาท (Matrix)"**
  - ผู้ดูแลระบบ (ADMIN) สามารถเข้าไปติ๊กเลือกสิทธิ์ของแต่ละบทบาท (`MANAGER`, `EDITOR`, `STAFF`) ได้อย่างอิสระครอบคลุม **10 โมดูลหลัก**:
    - **เห็นเมนู (Read / View)**
    - **เพิ่มข้อมูล (Add / Create)**
    - **แก้ไขข้อมูล (Edit / Update)**
    - **ลบข้อมูล (Delete)**
  - มีปุ่มทางลัด: `เปิดทุกสิทธิ์`, `อ่านอย่างเดียว`, `ปิดทั้งหมด`, `ค่าเริ่มต้น`
  - บันทึกลงฐานข้อมูลใน Setting `rolePermissions`
  - **แถบเมนู Sidebar ซ่อน/แสดงตามสิทธิ์ View ทันที:** หากบทบาทใดไม่มีสิทธิ์ดูโมดูลนั้น เมนูจะถูกซ่อนออกจากแถบซ้ายอัตโนมัติ
  - **ควบคุมปุ่มคำสั่งในหน้าข้อมูล:** ปิดการแสดงปุ่ม `+ เพิ่มรายการ` หากไม่มีสิทธิ์ Add และปิดการแสดงปุ่ม `ลบข้อมูล` หากไม่มีสิทธิ์ Delete

- **พรีวิวหน้าเว็บจริงแบบ Realtime เต็มหน้าจอ (Live Preview Modal):** มีปุ่มดูตัวอย่างหน้าเว็บจริงทุกฟอร์มใน Admin เปิดเป็น Popup เต็มจอ สลับดูได้ทั้งภาษาไทย/อังกฤษ และหน้าจอมือถือ/คอมพิวเตอร์ ข้อมูลเปลี่ยนตามที่พิมพ์ทันที
- **แยกเมนูซาลอนและเคาน์เตอร์แบรนด์ออกจากกัน 100%:** เมนูซ้ายแยกเป็น "ผลิตภัณฑ์ซาลอน (/products)" กับ "เคาน์เตอร์แบรนด์ (/shop)" พร้อมระบบจัดการหน้าเคาน์เตอร์แบรนด์, อัปโหลดรูปคุณเอมี่ (CEO) และจัดการ 14 เคาน์เตอร์แบรนด์โดยเฉพาะ
- **ระบบสิทธิ์ผู้ใช้งาน (Role RBAC) และตารางกำหนดสิทธิ์ (Permissions Matrix):**
  - มี 4 ระดับสิทธิ์: ผู้ดูแลระบบสูงสุด (ADMIN), ผู้จัดการระบบ (MANAGER), ผู้ดูแลเนื้อหา (EDITOR), ทีมงานทั่วไป (STAFF)
  - แอดมินสามารถเข้าไปติ๊กเลือกสิทธิ์ของแต่ละบทบาทได้เองอย่างละเอียด (กำหนดว่าเห็นเมนูไหน ทำอะไรได้บ้าง: ดู, เพิ่ม, แก้ไข, ลบ) เมนูซ้ายมือและปุ่มคำสั่งจะปรับตามสิทธิ์อัตโนมัติ
- **หน้าเปลี่ยนรหัสผ่านผู้ใช้หลังบ้าน (`/profile`):** ผู้ใช้สามารถกดที่ชื่อตัวเองหรือไอคอนกุญแจมุมซ้ายล่างเพื่อดูข้อมูลบัญชีและเปลี่ยนรหัสผ่านได้เอง
- **บทความและกิจกรรมใส่รูปได้หลายรูป:** อัปเกรดเป็นกล่องลากวางรูปภาพหลายรูป (Image Gallery) และแสดงแกลเลอรี่ภาพพร้อม Lightbox บนหน้าเว็บ

**ปรับปรุงและแก้ไข**
- หมวดหมู่หลักในสินค้าเคาน์เตอร์แบรนด์ไม่บังคับแล้ว (สามารถเว้นว่างได้ ไม่ติดดอกจันบังคับ)
- สลับลำดับขั้นตอนใน Admin ให้สร้างหมวดหมู่ก่อนสร้างรายการข้อมูล (มีเดีย และ ฟอรั่ม)
- ปรับปรุงระบบล้างแคชหน้าเว็บ เมื่อบันทึกข้อมูลใน Admin แล้ว หน้าเว็บจริงจะอัปเดตทันที
