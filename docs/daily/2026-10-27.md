# Daily Log — 27 ตุลาคม 2569

## สรุปภาพรวมการพัฒนาประจำวัน
วันนี้เป็นการพัฒนาและปรับปรุงระบบหลังบ้าน (Admin Panel) และหน้าบ้าน (Web Frontend) ครั้งใหญ่ใน 6 ส่วนหลัก:
1. **ระบบแกลเลอรี่รูปภาพหลายรูปสำหรับบทความและกิจกรรม** (`posts`)
2. **จัดระเบียบโครงสร้างเมนู แยกมีเดีย ออกจากบทความ/กิจกรรม และเรียงหมวดหมู่ก่อนรายการ**
3. **ระบบพรีวิวหน้าเว็บจริงแบบ Realtime เต็มหน้าจอ (Live Preview Modal) พร้อมปุ่มปิดและสลับโหมด Desktop/Mobile**
4. **แยกการจัดการผลิตภัณฑ์ซาลอน (`/products`) และเคาน์เตอร์แบรนด์ (`/shop`) ออกจากกัน 100% พร้อมระบบจัดการเนื้อหาหน้าเคาน์เตอร์แบรนด์และรูป CEO**
5. **ปรับให้หมวดหมู่หลักในสินค้าเคาน์เตอร์แบรนด์ไม่บังคับ (Optional)**
6. **ระบบสิทธิ์ผู้ใช้งานหลายระดับ (Multi-Role RBAC), หน้าเปลี่ยนรหัสผ่านผู้ใช้ (`/profile`), และตารางจัดการสิทธิ์แบบละเอียด (Granular Permissions Matrix: Read, Add, Edit, Delete)**

## สิ่งที่ทำวันนี้โดยละเอียด

### 1. ระบบแกลเลอรี่ภาพหลายรูปสำหรับบทความและกิจกรรม (`posts`)
- **ฐานข้อมูล & Admin:**
  - เพิ่มฟิลด์ `images String[] @default([])` ในโมเดล `Post`
  - ปรับปรุงฟอร์มใน Admin จากช่องใส่รูปเดี่ยว (`coverUrl`) เป็น **`ImageGallery`** รองรับการลากวาง (Drag & Drop) หลายรูปพร้อมกัน สลับลำดับภาพ และกำหนดรูปแรกเป็นรูปปกอัตโนมัติ
  - ทำงานร่วมกับระบบ SEO Auto-Rename เปลี่ยนชื่อไฟล์รูปภาพทุกรูปในแกลเลอรี่ให้สื่อความหมายตามชื่อบทความและแท็ก
- **หน้าเว็บ (`apps/web`):**
  - ในหน้ารายละเอียดบทความและกิจกรรม (`/[lang]/members/[type]/[slug]`) แสดงแกลเลอรี่ภาพแบบเต็มรูปแบบ (`MediaGallery`) พร้อมรูปย่อ (Thumbnails), ป้ายนับจำนวนภาพ และ Lightbox ขยายดูภาพขนาดใหญ่

### 3. ระบบพรีวิวหน้าเว็บจริงแบบ Realtime เต็มหน้าจอ (Live Preview Modal)
- **เพิ่มหน้าต่างพรีวิว `ResourcePreviewModal`:**
  - เพิ่มปุ่ม **"Preview ดูตัวอย่างหน้าเว็บ"** ด้านบนของทุกฟอร์มแก้ไขข้อมูลใน Admin
  - แสดงผลเป็น Popup เต็มหน้าจอ (Full-screen Overlay) มีปุ่มปิดชัดเจนที่มุมขวาบน (`✕ ปิดตัวอย่าง`)
  - มีปุ่มสลับภาษา **ไทย (TH) / อังกฤษ (EN)** และปุ่มสลับโหมดแสดงผล **เดสก์ท็อป (Desktop) / มือถือ (Mobile)**
  - อัปเดตการแสดงผลตามค่าในฟอร์มแบบ Realtime ทันทีโดยไม่ต้องกดบันทึกลงฐานข้อมูลก่อน
  - จัดการเรื่อง URL รูปภาพให้อัตโนมัติ (คงค่า URL จาก DigitalOcean Spaces / CDN และแปลง Local Blob ได้ถูกต้อง)
  - จัดโครงสร้าง Single-Column แบบ Responsive บนโหมด Mobile เสมือนดูผ่านหน้าจอมือถือจริง
- **รองรับการพรีวิวครบทุก Resource สำคัญ:**
  - **แบรนด์ (`brands`):** พรีวิวหน้าตาส่วนแบรนด์แบบเดียวกับหน้า `/th/products` จริง (พื้นหลังขาว โลโก้ คำอธิบาย ป้ายจุดเด่น และปุ่มโซเชียล)
  - **หมวดหมู่หลัก (`main-categories`):** พรีวิวหัวเรื่องหมวด และการ์ด Grid แสดงคอลเลกชันในหมวด
  - **คอลเลกชัน (`categories`):** พรีวิวแบนเนอร์คอลเลกชัน คำโปรย และการ์ดสินค้าในคอลเลกชัน
  - **สินค้า (`products`):** พรีวิวหน้าสินค้าจริง แกลเลอรี่ภาพสลับดูได้ ราคา ป้ายโปรโมชั่น แท็ก SEO และกล่องติดต่อสั่งซื้อ
  - **เนื้อหาเคาน์เตอร์แบรนด์ (`shopPage`):** พรีวิวส่วน Hero, ตาราง 14 เคาน์เตอร์แบรนด์, ส่วนคำพูดและรูป CEO (`From the CEO - I'm Amy`), และรายการสินค้า

### 4. แยกการจัดการผลิตภัณฑ์ซาลอน (`/products`) และเคาน์เตอร์แบรนด์ (`/shop`) ออกจากกัน 100%
- **แยกเมนูซ้ายมือ (Sidebar):**
  - **ผลิตภัณฑ์ซาลอน (`/products`):** จัดการเฉพาะแบรนด์/หมวด/สินค้าประเภท `SALON` (เช่น Fanola, Nook, Sweet ฯลฯ)
  - **เคาน์เตอร์แบรนด์ (`/shop`):** จัดการเฉพาะแบรนด์/หมวด/สินค้าประเภท `COUNTER` (เช่น La Prairie, La Mer, Dior ฯลฯ)
- **แถบขั้นตอนเฉพาะของเคาน์เตอร์แบรนด์ (Section Flow Bar):**
  - `1. เนื้อหาหน้า & รูป CEO (/shop)` (`/content/shopPage`): แก้ไขข้อความส่วนหัว, ข้อความคำพูด CEO, และอัปโหลดรูปคุณเอมี่ (`ceoImageUrl`)
  - `2. แบรนด์เคาน์เตอร์` (`/r/brands?type=COUNTER`): เพิ่มและแก้ไข 14 เคาน์เตอร์แบรนด์
  - `3. หมวดหมู่หลัก` (`/r/main-categories?type=COUNTER`): หมวดหมู่สำหรับเคาน์เตอร์แบรนด์
  - `4. สินค้าเคาน์เตอร์แบรนด์` (`/r/products?type=COUNTER`): รายการสินค้าเคาน์เตอร์แบรนด์ โดยตัวเลือกแบรนด์จะกรองเฉพาะแบรนด์เคาน์เตอร์ ไม่ปะปนกับซาลอน
- **การปรับปรุงการดึงข้อมูลบนหน้าเว็บ (`apps/web`):**
  - เพิ่มฟังก์ชัน `getShopPageData()` ดึงข้อมูลจากคีย์ `shopPage` ใน API `/public/settings`
  - หน้า `/th/shop` ดึงรูปคุณเอมี่และข้อความได้อย่างแม่นยำ พร้อมระบบ Fallback และแสดงโลโก้แบรนด์เคาน์เตอร์เมื่อมีการอัปโหลด
  - เพิ่มระบบตัวกรองสินค้าตาม **แบรนด์** และ **หมวดหมู่หลัก** บนหน้า `/th/shop`
  - ปรับปรุงระบบ **Instant Cache Revalidation** (`revalidateWeb` + Fallback Secret) เพื่อให้เมื่อกดบันทึกใน Admin หน้าเว็บจะล้างแคชและอัปเดตข้อมูลใหม่ทันที

### 6. ระบบสิทธิ์ผู้ใช้งาน (RBAC), หน้าเปลี่ยนรหัสผ่าน (`/profile`), และตารางจัดการสิทธิ์ละเอียด (Permissions Matrix)
- **เพิ่มระดับสิทธิ์ (Role Enum):**
  - เพิ่ม Enum Role ในฐานข้อมูลและ TypeScript:
    1. **`ADMIN`** (ผู้ดูแลระบบสูงสุด): สิทธิ์เต็มทุกส่วนในระบบ
    2. **`MANAGER`** (ผู้จัดการระบบ): จัดการสินค้า แบรนด์ เนื้อหา เมนู และข้อความสอบถาม
    3. **`EDITOR`** (ผู้ดูแลเนื้อหา): จัดการหน้าเว็บ บทความ กิจกรรม มีเดีย และฟอรั่ม
    4. **`STAFF`** (ทีมงานทั่วไป): ดูและตอบข้อความสอบถาม ตรวจสอบสินค้า
  - สร้าง Migration `20261027135000_add_roles` และผูกคำสั่ง `prisma generate` ให้อัตโนมัติเมื่อสั่ง build API
- **หน้าบัญชีผู้ใช้และเปลี่ยนรหัสผ่าน (`/profile`):**
  - เพิ่มหน้า `/profile` เข้าถึงได้จากเมนู Sidebar และไอคอนลูกกุญแจ 🔑 มุมซ้ายล่าง
  - แสดงข้อมูลผู้ใช้และป้ายสิทธิ์
  - ฟอร์มเปลี่ยนรหัสผ่าน: ตรวจสอบรหัสผ่านเดิม, บังคับรหัสผ่านใหม่อย่างน้อย 8 ตัวอักษร, ยืนยันรหัสผ่านใหม่, มีปุ่มเปิด/ปิดตาดูรหัสผ่าน และแจ้งเตือนสถานะทันที
  - API endpoint: `PUT /api/auth/password` ตรวจสอบความถูกต้องด้วย bcrypt
- **ตารางจัดการสิทธิ์ตามบทบาท (Granular Permissions Matrix):**
  - ในหน้า **ผู้ใช้หลังบ้านและการกำหนดสิทธิ์ (`/users`)** เพิ่มแท็บ **"กำหนดสิทธิ์ตามบทบาท (Matrix)"**
  - ผู้ดูแลระบบ (ADMIN) สามารถเข้าไปติ๊กเลือกสิทธิ์ของแต่ละบทบาท (`MANAGER`, `EDITOR`, `STAFF`) ได้อย่างอิสระครอบคลุม **10 โมดูลหลัก**:
    - **เห็นเมนู (Read / View)**
    - **เพิ่มข้อมูล (Add / Create)**
    - **แก้ไขข้อมูล (Edit / Update)**
    - **ลบข้อมูล (Delete)**
  - มีปุ่มทางลัด: `เปิดทุกสิทธิ์`, `อ่านอย่างเดียว`, `ปิดทั้งหมด`, `ค่าเริ่มต้น`
  - บันทึกลงฐานข้อมูลใน Setting `rolePermissions`
  - **แถบเมนู Sidebar ซ่อน/แสดงตามสิทธิ์ View ทันที** หากบทบาทใดไม่มีสิทธิ์ดูโมดูลนั้น เมนูจะถูกซ่อนออกจากแถบซ้ายอัตโนมัติ
  - **ควบคุมปุ่มคำสั่งในหน้าข้อมูล:** ปิดการแสดงปุ่ม `+ เพิ่มรายการ` หากไม่มีสิทธิ์ Add และปิดการแสดงปุ่ม `ลบข้อมูล` หากไม่มีสิทธิ์ Delete
