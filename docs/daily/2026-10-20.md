### 3. แก้ปัญหา deploy บน server — Admin ขึ้น error 500

- **สาเหตุ:** migration `20261015045600_brand_categories_relation` ค้างมาตั้งแต่ก่อนหน้านี้ ไม่เคย apply บน production ตาราง `Category` ถูกสร้างไว้แล้ว (น่าจะมาจาก `db push` ในอดีต) แต่ระบบ migration ไม่รู้ พอสั่ง `migrate deploy` เลย error "Category already exists"
- **ตรวจสอบก่อนแก้:** ตาราง, คอลัมน์ `Product.categoryId` และ index ครบหมด ขาดแค่ foreign key 2 ตัว และไม่มีข้อมูลที่อ้างอิงผิด (Category มีข้อมูล 20 แถว ไม่ได้ลบ)
- **วิธีแก้:** เพิ่ม foreign key 2 ตัวที่ขาด → `prisma migrate resolve --applied` migration เก่า → `prisma migrate deploy` apply migration คอร์สรูปภาพ → rebuild + reload
- **ปัญหาข้างเคียง:** ไฟล์ `apps/api/.env` บน server มี line ending แบบ Windows (CRLF) ทำให้ `psql` อ่าน connection string ผิด แก้ด้วย `sed -i 's/\r$//' .env` (ค่าข้างในไม่เปลี่ยน)
- ผลลัพธ์: ประวัติ migration บน server ตรงกับโค้ดแล้ว รอบ deploy ถัดไปจะไม่ติดปัญหานี้อีก ✅

- บน server: สร้างหมวดหมู่ฟอรั่มและเพิ่มเมนู "ฟอรั่ม" บนหน้าเว็บแล้ว ✅
- ⚠️ ยังไม่ได้ทดสอบการกดโพสต์ผ่านเบราว์เซอร์จริง และหน้าจอ Admin ของฟอรั่ม (ตัว API ทดสอบผ่านแล้ว)
