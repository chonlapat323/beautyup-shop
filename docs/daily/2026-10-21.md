- แก้การ์ดหมวดหมู่ของแบรนด์ได้ที่เดียว: เมนูและหน้าเว็บ

### 5. รวมการจัดกลุ่มสินค้าเหลือแบบเดียว: "คอลเลกชัน"

- เดิมหน้าแบรนด์จัดกลุ่มสินค้า 3 แบบพร้อมกัน คือแถบซีรีส์ยอดนิยม, หมวดหมู่ที่พิมพ์เองในหน้าสินค้า และหมวดหมู่ (Categories) ส่วนหน้าคอลเลกชันใช้วิธีเดาสินค้าจากชื่อ ไม่ได้ดูจากที่เลือกใน Admin
- ตอนนี้สินค้ามีช่องเดียวคือ "คอลเลกชัน" (เลือกจากรายการ ซึ่งมีชื่อแบรนด์กำกับ) หน้าคอลเลกชันและหัวข้อในรายการสินค้าของแบรนด์ใช้ช่องนี้ทั้งหมด
- ตัดออก: แถบซีรีส์ยอดนิยม (เว็บและหน้าแก้ไขแบรนด์), ช่อง "หมวดหมู่สินค้าเดิม" และ "ซีรีส์เดิม" ในหน้าสินค้า, กฎเดาสินค้าที่เขียนไว้ในโค้ด และรายการคอลเลกชัน Fanola สำรองที่เขียนไว้ในโค้ด
- Admin เปลี่ยนชื่อเมนู "หมวดหมู่ (Categories)" เป็น "คอลเลกชัน"
- ตอน deploy ระบบจะใส่คอลเลกชันให้สินค้าเดิมอัตโนมัติตามกฎเดิม แล้วจึงลบช่องเก่า หน้าคอลเลกชันจึงแสดงสินค้าชุดเดิม
- คอลเลกชันที่ไม่มีสินค้าจะขึ้นว่าไม่พบสินค้า (เดิมแสดงสินค้าทั้งแบรนด์)
- ⚠️ ยังไม่ได้ทดสอบ migration กับฐานข้อมูลจริง (Docker ปิดอยู่)

**Commit:** `9671429`

### 6. จัด Admin ให้แต่ละเนื้อหาแก้ได้ที่เดียว

- หน้า /products: หัวเรื่อง สไลด์ สไลด์ทรงผมวงรี และส่วนเนื้อหาทั้งหมด แก้ได้ที่เดียวคือเมนู "สินค้า" ใน เมนูและหน้าเว็บ (เดิมข้อมูลกระจายอยู่ 3 ที่ และหน้าเว็บอ่านหัวเรื่องจากค่าที่ Admin เข้าไม่ถึง)
- ตอน deploy ระบบย้ายข้อมูลหน้า /products จากค่าตั้งค่าเดิมมาไว้ที่เมนูให้อัตโนมัติ แล้วลบค่าตั้งค่าเดิม
- หน้า /products ไม่ดึงสไลด์หน้าแรกมาแสดงแทนแล้ว ถ้าเมนูไม่มีสไลด์ก็ไม่แสดงสไลด์
- หัวเรื่องในเมนูใช้ได้กับทุกหน้าที่สร้างจากเมนู ส่วนหน้าแบรนด์ใช้ชื่อและคำอธิบายจากเมนู แบรนด์
- หน้าเกี่ยวกับเรา, สไลด์หน้าเกี่ยวกับเรา, เส้นทางของบิวตี้อัพ และแบนเนอร์ VIP Customer มีเมนูของตัวเองใน sidebar ที่เดียว หน้า "ตั้งค่าเว็บไซต์" เหลือเฉพาะข้อมูลที่ใช้หลายหน้า (ข้อมูลบริษัท, แถบ Grow Your Vision, จำนวนซาลอนแต่ละภาค)
- ลบหน้า products-page เก่าใน Admin ที่ไม่ได้ใช้แล้ว
- URL ซ้ำ: เมนูที่มีเนื้อหาของตัวเองกับหน้าเนื้อหาใช้ URL เดียวกันไม่ได้แล้ว ระบบแจ้งเตือนตอนบันทึก ส่วนเมนูที่เป็นแค่ลิงก์ไปหน้าเนื้อหาจะแสดงหน้าเนื้อหานั้นตามปกติ (เดิมหน้าเนื้อหาถูกบังด้วยหน้าว่างของเมนู)
- ⚠️ ยังไม่ได้ทดสอบ migration และหน้าเว็บตอนรันจริง (Docker ปิดอยู่)
