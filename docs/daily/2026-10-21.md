### 5. รวมการจัดกลุ่มสินค้าเหลือแบบเดียว: "คอลเลกชัน"

- เดิมหน้าแบรนด์จัดกลุ่มสินค้า 3 แบบพร้อมกัน คือแถบซีรีส์ยอดนิยม, หมวดหมู่ที่พิมพ์เองในหน้าสินค้า และหมวดหมู่ (Categories) ส่วนหน้าคอลเลกชันใช้วิธีเดาสินค้าจากชื่อ ไม่ได้ดูจากที่เลือกใน Admin
- ตอนนี้สินค้ามีช่องเดียวคือ "คอลเลกชัน" (เลือกจากรายการ ซึ่งมีชื่อแบรนด์กำกับ) หน้าคอลเลกชันและหัวข้อในรายการสินค้าของแบรนด์ใช้ช่องนี้ทั้งหมด
- ตัดออก: แถบซีรีส์ยอดนิยม (เว็บและหน้าแก้ไขแบรนด์), ช่อง "หมวดหมู่สินค้าเดิม" และ "ซีรีส์เดิม" ในหน้าสินค้า, กฎเดาสินค้าที่เขียนไว้ในโค้ด และรายการคอลเลกชัน Fanola สำรองที่เขียนไว้ในโค้ด
- Admin เปลี่ยนชื่อเมนู "หมวดหมู่ (Categories)" เป็น "คอลเลกชัน"
- ตอน deploy ระบบจะใส่คอลเลกชันให้สินค้าเดิมอัตโนมัติตามกฎเดิม แล้วจึงลบช่องเก่า หน้าคอลเลกชันจึงแสดงสินค้าชุดเดิม
- คอลเลกชันที่ไม่มีสินค้าจะขึ้นว่าไม่พบสินค้า (เดิมแสดงสินค้าทั้งแบรนด์)
- ⚠️ ยังไม่ได้ทดสอบ migration กับฐานข้อมูลจริง (Docker ปิดอยู่)
