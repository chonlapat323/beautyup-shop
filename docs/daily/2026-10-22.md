# Daily Log — 22 ตุลาคม 2569

## สิ่งที่ทำวันนี้

### 1. ตรวจ Admin หาจุดที่ยังซับซ้อน

- ตรวจทุกฟอร์มใน Admin เทียบกับหน้าเว็บ แบ่งเป็น 4 กลุ่ม: บั๊ก, ของซ้ำหรือช่องที่ไม่มีผลบนเว็บ, ค่าที่เขียนไว้ในโค้ดจนแอดมินแก้แล้วไม่เห็นผล, ชื่อและภาษา
- วันนี้แก้กลุ่มบั๊กก่อน กลุ่มอื่นรอทำต่อ (ดู "ต้องทำต่อ")

### 2. แก้บั๊กในหน้าแก้ไขเมนู

- เพิ่มสวิตช์ "แสดงเมนูนี้บนเว็บ", ช่องลำดับ และปุ่มลบเมนู (เดิมไม่มี จึงซ่อน เรียง หรือลบเมนูจาก Admin ไม่ได้)
- สร้างเมนูใหม่แล้วกลับไปหน้ารายการเมนูทันที (เดิมอยู่หน้าเดิม ถ้ากดบันทึกซ้ำจะได้เมนูซ้ำ)
- เอาตัวเลือก "ท้ายเว็บ (Footer Menu)" ออก เพราะท้ายเว็บใช้เมนูชุดเดียวกับหัวเว็บ เมนูที่ตั้งเป็นท้ายเว็บจึงไม่เคยขึ้นบนเว็บ เมนูเก่าที่ตั้งไว้แบบนี้จะมีข้อความเตือน และย้ายไปเมนูหลักเมื่อบันทึก
- ปุ่ม "เว็บจริง" ใช้ที่อยู่เว็บจาก `SITE_URL` (เดิมเขียนตายตัวเป็น new.beautyup-enterprise.com)
- แก้หัวตารางหน้ารายการหมวดหมู่มีเดียและหมวดหมู่ฟอรั่มที่ขึ้นผิดเป็น "ชื่อคอลเลกชัน"
- ⚠️ ยังไม่ได้ทดสอบตอนรันจริง (Docker ปิดอยู่)

## ต้องทำต่อ

- Deploy งานวันที่ 21 และวันนี้ (สำรองฐานข้อมูลก่อน)
- หลัง deploy: ลบเมนู "PP STUDIO" ได้จากปุ่มลบในหน้าแก้ไขเมนูแล้ว และลองซ่อน/เรียงเมนู
- Admin ที่เหลือจากการตรวจ:
  - ตัดของซ้ำและช่องที่ไม่มีผลบนเว็บ: การ์ดหมวดหมู่หลักประจำแบรนด์, แบรนด์ในสไลด์หน้าแรก, กลุ่ม Facebook ในข้อมูลบริษัท, ช่องที่ไม่ใช้ของแบรนด์เคาน์เตอร์, ช่องที่ไม่มีผลในบล็อกของตัวแก้ไขเมนู
  - ปรับชื่อและภาษา: ชื่อเดียวกันทุกที่, เลิกใช้คำอังกฤษเทคนิค, สร้าง slug อัตโนมัติ, ตัวเลือกสี, รวมเมนูหน้าเกี่ยวกับเราเป็นเมนูเดียว
  - รอเลือก: ค่าที่เขียนไว้ในโค้ด (สไลด์หน้าแรกสำรอง, การ์ด Fanola, รูปสำรอง, ปุ่มกรองในหน้าคอลเลกชัน, รายชื่อซาลอนชุดเก่า ฯลฯ) จะตัดออก ย้ายเข้า Admin หรือปล่อยไว้
