# Daily Log — 22 ตุลาคม 2569

## สิ่งที่ทำวันนี้

### 1. ตรวจ Admin หาจุดที่ยังซับซ้อน

- ตรวจทุกฟอร์มใน Admin เทียบกับหน้าเว็บ แบ่งเป็น 4 กลุ่ม: บั๊ก, ของซ้ำหรือช่องที่ไม่มีผลบนเว็บ, ค่าที่เขียนไว้ในโค้ดจนแอดมินแก้แล้วไม่เห็นผล, ชื่อและภาษา
- วันนี้แก้กลุ่มบั๊กก่อน กลุ่มอื่นรอทำต่อ (ดู "ต้องทำต่อ")

### 2. แก้บั๊กในหน้าแก้ไขเมนู

- เพิ่มสวิตช์ "แสดงเมนูนี้บนเว็บ", ช่องลำดับ และปุ่มลบเมนู (เดิมไม่มี จึงซ่อน เรียง หรือลบเมนูจาก Admin ไม่ได้)
- สร้างเมนูใหม่แล้วกลับไปหน้ารายการเมนูทันที (เดิมอยู่หน้าเดิม ถ้ากดบันทึกซ้ำจะได้เมนูซ้ำ)
- เอาตัวเลือก "ท้ายเว็บ (Footer Menu)" ออก เพราะท้ายเว็บใช้เมนูชุดเดียวกับหัวเว็บ เมนูที่ตั้งเป็นท้ายเว็บจึงไม่เคยขึ้นบนเว็บ เมนูเก่าที่ตั้งไว้แบบนี้จะมีข้อความเตือน และย้ายไปเมนูหลักเมื่อบันทึก
- ปุ่ม "เว็บจริง" ใช้ที่อยู่เว็บจาก `SITE_URL` (เดิมเขียนตายตัวเป็น new.beautyup-enterprise.com)
- แก้หัวตารางหน้ารายการหมวดหมู่มีเดียและหมวดหมู่ฟอรั่มที่ขึ้นผิดเป็น "ชื่อคอลเลกชัน"
- ⚠️ ยังไม่ได้ทดสอบตอนรันจริง (Docker ปิดอยู่)

**Commit:** `90e370a`

### 3. แก้บั๊กหน้าแบรนด์และตัวแก้ไขเมนู

- หน้าแบรนด์ภาษาอังกฤษ ส่วนเนื้อหาจากเมนูยังขึ้นภาษาไทย แก้แล้ว
- ช่องหัวเรื่องในตัวแก้ไขเมนู ซ่อนเฉพาะเมนูหน้าแบรนด์ (/products/ชื่อแบรนด์) เพราะหน้าแบรนด์ใช้ชื่อและคำอธิบายจากเมนู แบรนด์ หน้าอื่นแก้หัวเรื่องได้ทุกหน้า
- หน้าแบรนด์แสดงสินค้าของแบรนด์ตามลิงก์เสมอ ตัวแก้ไขเมนูของหน้าแบรนด์ไม่มีช่องเลือกแบรนด์แล้ว เหลือแค่เปิด/ปิดรายการสินค้า

### 4. ตัดช่องที่ไม่มีผลบนเว็บ

- การ์ด "หมวดหมู่หลักประจำแบรนด์": ตัดออกจากเว็บและระบบ หน้าแบรนด์ใช้เนื้อหาจากเมนูและคอลเลกชันเท่านั้น (ข้อมูลเดิมในฐานข้อมูลยังอยู่ ไม่ได้ลบ)
- ช่อง "แบรนด์" ในสไลด์หน้าแรก และ "กลุ่ม Facebook" ในข้อมูลบริษัท
- แบรนด์เคาน์เตอร์ซ่อนช่องสโลแกน, จุดเด่น, แคตตาล็อก และโซเชียล (เว็บไม่ได้แสดง)

### 5. ฟอร์ม Admin ใช้ง่ายขึ้น

- ช่อง slug เปลี่ยนชื่อเป็น "ชื่อในลิงก์ (URL)" และสร้างจากชื่อภาษาอังกฤษให้อัตโนมัติ แก้เองได้
- หน้าแก้ไขสินค้า ช่องคอลเลกชันแสดงเฉพาะคอลเลกชันของแบรนด์ที่เลือก เปลี่ยนแบรนด์แล้วช่องคอลเลกชันล้างให้
- สีประจำคอลเลกชันใช้ตัวเลือกสี
- ใช้ชื่อเดียวกันทุกที่: เมนูและหน้าเว็บ, หน้าข้อความ (เดิม หน้าเนื้อหา), วิดีโอหน้าแรก, มีเดีย, ซาลอนพันธมิตร, แบนเนอร์ลูกค้า VIP
- เปลี่ยนคำอังกฤษเทคนิคเป็นภาษาไทยทั้งในฟอร์มและตัวแก้ไขเมนู (Eyebrow, Hero, Moodboard, Component, Wix, Routing ฯลฯ)
- หน้าเกี่ยวกับเรา รวมเป็นเมนูเดียวใน sidebar มี 3 แท็บ: เนื้อหา, สไลด์, เส้นทางของบิวตี้อัพ
- รายการเมนูแสดงคอลัมน์ "อยู่ใต้เมนู" และ "ลำดับ"
- ⚠️ ยังไม่ได้ทดสอบตอนรันจริง (Docker ปิดอยู่)

## ต้องทำต่อ

- หลัง deploy: ลองซ่อน เรียง และลบเมนูในหน้าแก้ไขเมนู
- หลัง deploy ลองใช้ Admin: สร้างสินค้าใหม่ (ชื่อในลิงก์สร้างเอง, คอลเลกชันตามแบรนด์), หน้าเกี่ยวกับเรา 3 แท็บ, แบรนด์เคาน์เตอร์ซ่อนช่องที่ไม่ใช้
