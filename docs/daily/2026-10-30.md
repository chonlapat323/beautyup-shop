### กลุ่มที่ 1: SEO, Metadata และการรองรับ AI Crawler

#### 1. แก้ไข hreflang และ metadataBase ให้ชี้ตาม URL หน้าจริง (Hreflang & Canonical Alternates Fix)
- **ปัญหาเดิม:** ใน `layout.tsx` มีการตั้งค่า `alternates: { languages: { th: "/th", en: "/en" } }` แบบคงที่ไว้ระดับ Root ทำให้ทุกหน้าย่อย (เช่น `/th/about`, `/th/products`) ชี้ hreflang กลับไปยังหน้าแรกเสมอ ซึ่งผิดหลัก SEO สากล
- **การแก้ไข:**
  - เพิ่มฟังก์ชัน `langAlternates(path, currentLang)` ใน [site.ts](file:///f:/ATC_PRoject/wix/apps/web/src/lib/site.ts) รองรับการสร้างคู่ภาษา th / en และ canonical URL ตาม path จริง
  - นำค่าคงที่ออกจาก Root Layout และเพิ่ม `metadataBase: new URL(SITE_URL)`
  - กำหนด `alternates` ที่ถูกต้องให้กับหน้าสำคัญต่างๆ เช่น หน้าแรก, `/about`, `/products`, `/shop`, `/courses`, `/customers/salons`

#### 2. เพิ่มไฟล์มาตรฐาน AI Crawler (`/llms.txt`)
- **ปัญหาเดิม:** ยังไม่มีไฟล์ `/llms.txt` สำหรับให้ระบบ Large Language Model หรือ AI Crawler เข้ามาอ่านบริบท ข้อมูลบริษัท และบริการได้อย่างแม่นยำ
- **การแก้ไข:**
  - สร้างไฟล์ [llms.txt](file:///f:/ATC_PRoject/wix/apps/web/public/llms.txt) บรรจุข้อมูลบริษัท Beauty Up Enterprise, แบรนด์นำเข้า (Fanola, Oro Therapy ฯลฯ), บริการสำหรับซาลอน และโครงสร้าง URL สำคัญ
  - สร้าง Route Handler [llms.txt/route.ts](file:///f:/ATC_PRoject/wix/apps/web/src/app/llms.txt/route.ts) เพื่อเสิร์ฟไฟล์พร้อม Content-Type `text/plain; charset=utf-8` และ Cache-Control ที่เหมาะสม

#### 3. เพิ่ม Image Sitemap สำหรับรูปภาพในระบบ (`sitemap.ts`)
- **ปัญหาเดิม:** ใน `sitemap.ts` มีเฉพาะ URL หน้าเว็บ แต่ยังไม่มีแท็ก `<image:image>` ให้ Google ค้นหาและจัดทำดัชนีรูปภาพผลิตภัณฑ์หรือบทความ
- **การแก้ไข:**
  - ปรับปรุง [sitemap.ts](file:///f:/ATC_PRoject/wix/apps/web/src/app/sitemap.ts) โดยดึงรูปภาพของ สินค้า (Products), คอร์สอบรม (Courses), บทความ (Posts/News) และแบรนด์ (Brands) มาระบุในฟิลด์ `images` ของแต่ละรายการตามสเปก Sitemap ของ Next.js

#### 4. เพิ่มคำอธิบายรูป (Alt text) ในแกลเลอรีมีเดีย (`media-gallery.tsx`)
- **ปัญหาเดิม:** ใน [media-gallery.tsx](file:///f:/ATC_PRoject/wix/apps/web/src/components/media-gallery.tsx) แถวที่ 68 และ 140 มีการใส่ `alt=""` ว่างไว้ ทำให้รูปภาพไม่มี Accessibility และส่งผลเสียต่อการตรวจคะแนน SEO
- **การแก้ไข:**
  - กำหนดคำอธิบายภาพที่มีความหมายตามชื่อหัวข้อ เช่น `${title} - ภาพที่ ${i + offset + 1}` และ `${title} - ภาพย่อที่ ${i + 1}`

### กลุ่มที่ 2: ล้างข้อมูล Fallback และข้อมูล Mock ค้างในโค้ด (Fallback Cleanup)

#### 6. ลบรูปสินค้าสำรอง (`productFallbacks`)
- **ปัญหาเดิม:** ใน `data.ts` มีออบเจ็กต์ `productFallbacks` ที่ฮาร์ดโค้ด URL รูปภาพของสินค้า Fanola ไว้ในโค้ด

#### 7. ลบรูปแอมบาสเดอร์สำรอง (`fallbackPhotos`)
- **ปัญหาเดิม:** ใน `data.ts` มีการเก็บรูปสำรอง `fallbackPhotos` และการสร้าง Avatar สำรองแบบ SVG ฝังอยู่ในโค้ด

#### 8. ล้างรายชื่อซาลอนจำลองในหน้าเว็บ (`THAILAND_SALON_DIRECTORY`)
- **ปัญหาเดิม:** ใน `thailand-salons.ts` มีการจำลองรายชื่อซาลอนในไทยไว้ในโค้ดหน้าบ้าน
- **การแก้ไข:**
